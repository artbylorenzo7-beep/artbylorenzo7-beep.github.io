# Bashar's Atelier Artwork System

Each artwork should have its own folder:

```
artwork-name/
├── artwork.avif
├── artwork.webp
├── original.jpg
└── preview.jpg
```

Workflow:

1. Keep the original artwork archive offline.
2. Remove EXIF metadata before publishing.
3. Export optimized AVIF and WebP versions.
4. Use preview images for blur-up loading.
5. Add descriptive alt text for accessibility.
